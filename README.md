# DeepFakeDetector
Georgia Tech Machine Learning group project. Uses taught and researched ML algorithms to detect if inputted images are AI generated or not.


/docs/: Website Files

/backend/: Files for Web App Backend

/Model/archive/: Labeled Data Split into Test and Train

/Model/Preprocessing.ipynb/: Preprocessing Implementation

/Model/SVM.ipynb/: SVM Implemention
/Model/CNN.ipynb/: CNN Implementation
/Model/RF.ipynb/: Random Forest Implementation
/Model/Comparison.ipynb/: Method/Model comparison visualizations.
